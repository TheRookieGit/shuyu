# 爱妻的书屿

找到书库里有什么小说、按内容分类和题材 tag 筛选、查看字数、打开或定位文件，也可以用 Claude 生成清理建议、另存版本。可以记下想看但还没下载的书，给每本书备注下载地址。不提供内置阅读器，不记录阅读历史、阅读状态或笔记。

## Windows 应用

从 [Releases → 爱妻的书屿 Windows 版（最新）](https://github.com/TheRookieGit/shuyu/releases/tag/app-latest) 下载 `AiqiShuyu-windows.zip`，解压到任意位置，双击 **爱妻的书屿.exe**。不需要安装 Python，也不会出现黑色命令行窗口。

- 书屿在独立的应用窗口中打开，没有浏览器地址栏和标签页。窗口由 Windows 自带的 Edge 以应用模式显示；找不到 Edge 时改用默认浏览器。
- 关闭窗口不会停止书屿，后台继续在右下角托盘运行，网页版仍可连接。双击托盘图标可以重新打开窗口；要完全停止，在托盘图标的右键菜单中选「退出」。
- 托盘菜单中可以勾选 **开机自动启动**。开机后书屿只在托盘中运行，不弹出窗口。
- 已经在运行时再次双击 exe，会直接打开窗口，不会启动第二份。
- **自动更新，只需安装一次**：启动时、之后每 10 分钟，以及点托盘「检查更新」时，书屿会检查 GitHub 上的最新构建。发现新版后自动下载、替换程序并重启，完成后托盘弹出提示；扫描或 AI 任务进行中会等任务结束再更新。托盘菜单显示当前版本号和更新状态。请把应用文件夹放在桌面、文档等自己可以写入的位置，不要放在 `C:\Program Files`。
- 数据保存在 `%LOCALAPPDATA%\AiqiShuyu`，更新程序不会影响书库数据。
- **从 .bat 版迁移**：先关闭 .bat 窗口，把原项目里 `.data` 文件夹中的全部内容复制到 `%LOCALAPPDATA%\AiqiShuyu`（在资源管理器地址栏输入这个路径即可打开），再启动应用。分类、字数、清理版、AI 设置和访问密码都会保留。
- 应用版默认允许 GitHub 网页版连接，相当于带了 `--allow-origin https://therookiegit.github.io`。

每次推送到 `main`，`.github/workflows/windows-app.yml` 都会在 Windows 上运行测试、打包、试启动打包后的程序并更新这个 Release，再用一份旧版副本验证自动更新能升级到这次构建。已安装的应用会在 10 分钟内自动更新。

## 从源码启动

双击 **启动爱妻的书屿.bat**，浏览器会打开 <http://127.0.0.1:8765>。保持启动窗口开启；关闭窗口即停止服务。重复启动会复用同版后台；更新代码后重新双击，会自动将空闲后台切换到新版，再刷新页面即可。AI 或分类任务进行中时，先完成或停止任务再切换。

需要 Python 3.10 或更新版本。默认扫描 `Z:\老婆小说漫画`。

```powershell
python server.py
python server.py --root "D:\我的小说" --port 8766
python server.py --no-browser
python server.py --allow-origin https://therookiegit.github.io   # 允许 GitHub 网页版连接（启动 .bat 默认带此参数）
python server.py --lan   # 另外允许局域网内的电脑直接用 IP 访问
```

## 网页版（GitHub Pages）

网页版地址：<https://therookiegit.github.io/shuyu/>。任何电脑、平板、手机都可以在任何地方打开。网页只是界面；书库文件、数据库、清理版和 AI 任务都只在 Windows 电脑上保存和运行，所有设备看到的都是同一份数据，不需要另外同步。Windows 电脑需要开机，服务窗口要保持开启。

GitHub Pages 只托管 `web/` 中的静态页面，不包含任何书目数据。推送到 `main` 后，`.github/workflows/pages.yml` 会自动发布。第一次使用前，在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**。免费账户只能为公开仓库开启 Pages。

### 一次性设置（Windows 电脑）

1. 双击 **启动爱妻的书屿.bat**，在本机页面的「书库设置 → 网页版访问」里设置访问密码，至少 6 个字符。
2. 给后台一个固定的 HTTPS 地址。推荐用 [Tailscale Funnel](https://tailscale.com/kb/1223/funnel)，免费，不用买域名，也不用在路由器上开端口：
   - 安装 [Tailscale](https://tailscale.com/download) 并登录；在 Tailscale 管理后台开启 HTTPS 证书和 Funnel。
   - 在命令行运行一次：`tailscale funnel --bg 8765`。`--bg` 会让 Funnel 在重启后继续生效。
   - 记下输出的地址，例如 `https://windows-pc.tail1234.ts.net`，它就是「网页版地址」。
3. 把这个地址写进 `web/app.js` 的 `DEFAULT_SERVER` 并推送，网页版就不需要在设备上填写地址；只有连不上时才显示地址栏，也可以在登录页点「更换网页版地址」。
4. 在任意设备打开网页版，输入访问密码登录。每台设备只需登录一次：只要一年内用过，登录状态就会自动续期。

也可以使用 Cloudflare Tunnel 等其他 HTTPS 隧道，只要把流量转发到 `http://localhost:8765` 即可。网页版运行在 HTTPS 上，所以后台地址也必须是 HTTPS。

### 网页版的规则

- Windows 本机直接访问 `http://127.0.0.1:8765` 不需要密码，与以前一样。经由隧道或网页版来的请求一律需要登录，即使它们最终从本机回环地址进入。
- 网页版和其他设备上，「打开小说 / 定位小说」换成 **下载到这台电脑**：包内小说会自动取出后下载，图片目录会打包成一个 ZIP，也可以下载所选的清理版。下载链接 2 分钟内有效，只能使用一次。
- 设置访问密码、重启后台、打开或定位文件只能在 Windows 电脑上操作；分类、AI 清理、书库设置等其他功能网页版也可以使用。
- 修改访问密码后，所有设备都需要重新登录；网页上「退出登录」只退出当前设备。连续输错 5 次密码会暂时锁定该来源。
- 只有 `--allow-origin` 列出的网页可以跨站调用后台。如果把网页部署到其他地址，启动时加上对应的 `--allow-origin`。

## 书屿 Lite（只做 AI 处理）

书屿 Lite 是一个只用来 AI 处理小说的精简页面，地址是 <https://therookiegit.github.io/shuyu/lite/>，Windows 本机打开 <http://127.0.0.1:8765/lite/>；完整版顶栏的 **书屿 Lite** 按钮也能进去。它连接同一个 Windows 后台，使用同一个访问密码；在一边登录过，另一边就不用再登录。

1. 搜索或从最近发现的书里选一本 TXT / EPUB，或者切换到 **上传一本**，从手机或其他电脑上传 TXT、MD、EPUB（每本 64 MB 以内），或者 ZIP、RAR、7Z 等压缩包（512 MB 以内），可以一次选多个。书名和作者会从文件名和书里自动识别，需要时可以修改；压缩包会在 Windows 电脑上自动解压（包括包中包），里面每本 TXT、MD、EPUB 都识别书名作者后单独保存，PDF、Word 等其他文件不导入，上传后会提示数量。
2. 勾选要做的事：删除作者有话说 / 广告、修复乱码、推测屏蔽字，或者 **按我的要求修改**，写一段自己的要求（1000 字以内），例如统一人名、删除每章末尾的固定文字。按要求修改时，Claude 会逐段检查全文，用量较大。
3. 逐条确认建议，另存为这本书的新版本，然后可以直接下载。原文件和已有版本都不会改动；可以在新版本上继续处理，每次都另存一个版本。选好书后展开 **全部版本、下载与上传**，原文件和每个版本都能下载或传到微信读书。

一次上传多本时，这一批用同样的设置、从原始版本开始，一本接一本处理（每本同时发送 4 个片段），关掉页面也会继续；处理完的书在列表里点「确认建议」逐本确认、另存。费用只按实际用量计算，一次处理多本不会多花钱。参考：一本 82 万字的书用 API「优先检查疑似片段」约用 42 万输入、2.7 万输出 tokens，按 Haiku 5.5 的价格约 0.06 美元；「逐段检查全文」或按要求修改大约是它的 3～5 倍。

### 上传的书和清理版放在哪里

上传的书保存在 Windows 书库的 `Lite上传` 文件夹里，文件名是 `《书名》作者：作者【lite上传】.txt`（没填作者就省略作者部分，同名时加（2）），上传后立即出现在书架上，完整版里也能看到。上传的压缩包也原样保存在这个文件夹里，文件名是 `原名【lite上传】.zip`；因为里面的小说已经单独保存，扫描书库时不会再展开这些压缩包。它们的清理版和原文件放在一起，命名为 `《书名》作者：作者【AI清理版1】.txt`，编号就是版本号；扫描书库时会跳过这些清理版，所以不会变成重复的书。之前存在数据目录里的上传书清理版，会在书屿启动时自动搬到这里。书库里其他书的清理版仍然保存在 `%LOCALAPPDATA%\AiqiShuyu\versions`，在完整版里选好版本后点「定位小说」就能找到。

新增小说自动清理会跳过 `Lite上传` 文件夹，由你在 Lite 里自己处理；自定义要求也只在手动处理时使用。

### 从网盘链接下载

第一步切换到 **网盘链接**，粘贴夸克网盘或百度网盘的分享链接（提取码可以一起粘贴，`?pwd=` 也行；一次可以粘贴多个链接），点 **从网盘下载到 Windows 书库**。Windows 电脑会把分享里的 TXT、MD、EPUB 小说和压缩包（包括子文件夹里的）转存到你自己网盘的 `书屿转存` 文件夹，再下载到书库的 `Lite上传` 文件夹，和上传的书一样识别书名作者、自动解压；图片、PDF 等其他文件会跳过并提示。下载完一本就直接进入处理，多本则作为一批。

第一次用某个网盘时会弹出二维码：夸克用夸克 App 扫，百度用百度网盘 App 扫，然后在手机上确认。夸克的二维码大约 3 分钟过期，过期后会自动换新。登录保存在 Windows 电脑上（加密后存在 `library.sqlite3` 里），**网盘链接** 下面显示两个网盘的登录账号，可以退出。和微信读书一样，这是照着两个网盘网页版的做法实现的，不是官方接口；网盘改版后，可能要更新书屿才能继续使用。非会员的下载速度会被网盘限制，大压缩包可能要等一会儿。

### 传到微信读书

另存版本后点 **上传到微信读书**，Windows 电脑会把这个版本直接传到你的微信读书书架，以书名命名。不需要 AI 处理的书，选好书和版本后在第一步就能直接上传、下载或分享。完整版书屿的书目详情里也有 **传到微信读书**，传的是当前选中的版本。

第一次会弹出二维码，用微信扫码并在手机上确认；微信读书要求验证码时，在弹窗里填上。在同一部手机上没法扫码时，可以复制登录链接，发到微信里自己点开确认。登录保存在 Windows 电脑上（加密后存在 `library.sqlite3` 里），完整版和 Lite 共用；过期时会先自动续期，续不上再请你重新扫码。两个页面右上角都显示 **微信读书** 的登录状态和账号名，点开可以登录、换一个账号或退出。

这是照着 weread.qq.com/web/upload 的上传方式做的（扫码登录、取得腾讯云 COS 临时凭证、分片上传，再通知微信读书导入），不是官方接口；微信读书改版后，可能要更新书屿才能继续使用。

支持系统分享的手机和电脑上还会出现 **分享到其他应用**：先从 Windows 电脑取回文件，再打开系统分享面板，可以选微信读书 App 或其他应用。手机浏览器有时要求点第二次才能打开分享面板，按钮会提示。

### Claude 设置

Lite 右上角的 **Claude 设置** 只影响 Lite：可以和完整版分别选择 Claude API 或 Windows 电脑上的 Claude Code 订阅。还没单独设置时沿用完整版的设置，也可以随时改回沿用。

Windows 电脑关机、书屿没有运行或隧道断开时，Lite 会弹出提示，说明要检查什么，并提供「重新连接」。Lite 的页面在 `lite/` 目录中，和完整版的 `web/` 分开；推送后由同一个 Pages 流程一起发布。

## 书库文件夹

点顶栏的 **文件夹** 按钮，可以查看 Windows 书库里每个子文件夹和压缩包各有多少本小说。每一行显示的是它里面所有书的数量，包括更深的子文件夹和多层套包；有重复副本时，会同时显示去重后的本数，有漫画的会单独列出漫画数。点一行展开下一层，可以一直点进压缩包内部的文件夹和更深一层的压缩包；点书名会打开这本书的详情。一整个图片文件夹算作一部漫画，不会再展开。每一层最多列出 200 本书，其余的可以用搜索查找。

## 想看清单与下载地址

- 书架上方切换到 **想看 · 未下载**，点「添加想看」记下准备看、还没下载的书：填写书名，类型可选 **小说文件、文件夹、ZIP 压缩包**，作者、下载地址和备注都是可选的。想看的书在书架上显示为虚线边框。
- 下载到 Windows 书库后，扫描时如果发现书名、所在文件夹名或压缩包名相同的书，会自动标为「已到书架」，点开就是那本书；写了作者的，作者不同时不会匹配。想看记录里的下载地址也会带到这本书上。
- 每本书的详情里都可以填写 **下载地址**，同一本书的各个来源副本共用一个地址。只接受 http:// 或 https:// 地址。

## 新增小说自动清理

书库里新增的 TXT / EPUB 小说，在扫描之后会自动用 Claude 清理，选项和手动清理默认的一样：作者有话说 / 广告、乱码修复、屏蔽字推测，优先检查疑似片段，自动识别编码。

- 自动采用的修改只有默认勾选的高置信度作者话 / 广告删除，另存为同一本书的「自动清理版」。**原文件、原压缩包和已有版本都不会改动。**
- 乱码修复和屏蔽字推测的建议不会自动采用，会保留在清理任务里。书目详情里会显示「自动清理 · 有建议待确认」，点「查看清理任务」可以逐条勾选后再另存一个版本。
- 没有发现标记的书不会生成新版本。这个功能第一次运行时只会记下起点，开启前已经在书库里的书不会被批量清理；关闭后再开启也一样，只处理开启之后新增的书。重复来源、已经有清理版的书会跳过。
- 使用「Claude AI 设置」里选择的 API 或本机 Claude Code 订阅，会占用相应用量。还没配置 Claude 时，新书会排队等待，不会失败。在「书库设置 → 新增小说自动清理」可以关闭这个功能、查看最近的处理结果，或重试失败的书。
- 新增的书在扫描后也会自动进行本地分类和字数统计。这一步不调用 Claude。

## 手机网页

屏幕宽度不超过 760px 时，网页切换为手机布局：

- 底部导航栏：书架、想看、筛选、设置。顶部栏和搜索框在滚动时固定在屏幕上方。
- 筛选从底部弹出，按钮上显示当前条件下的结果数量（「查看 N 本」）；导航栏的筛选图标会显示已选条件的数量。
- 书架每行 3 本，屏幕很窄时每行 2 本。书目详情、设置、清理和想看编辑都是全屏页面，按钮至少 44px 高，方便手指点按。输入框使用 16px 字号，避免 iPhone 聚焦时自动放大页面。

## 自动处理压缩包

- 汇总所有子目录，不要求先整理文件夹。
- 自动逐层展开 ZIP、RAR、7Z、CBZ、CBR 等压缩包，直接把包内小说列到书架上，包括多层套包。
- 纯图片压缩包或纯图片目录作为一部漫画展示，不逐张列图。
- TXT、EPUB / EQPUB、PDF、DOCX、DOC、MOBI、AZW / AZW3、RTF、MD、HTML、FB2 等按书目展示；内容交给系统关联应用打开。
- 初次运行会从 [7-Zip 官方发布](https://www.7-zip.org/download.html)下载并校验便携解压引擎，放在 `.data/tools`，不安装到系统。准备好后可离线使用。
- 只在项目的 `.data/extracted` 中缓存需要取出的嵌套压缩包和文件，不改动源目录，不要求逐个手动解压。
- 未变化的目录清单及已取出的文件会复用缓存。首次扫描大量嵌套合集可能较慢，扫描期间已有结果仍可搜索。手动扫描会自动重试失败的压缩包。

确有密码的文件仍需要正确密码。在「书库设置」填写常用解压密码，每行一个，程序会自动尝试并重新扫描。解压密码只保存在本机，扫描、搜索和解压都在本地完成。只有手动开始 AI 检查时，所选小说片段才会通过 API 或本机 Claude Code 发送到 Claude 服务。

损坏、缺卷、没有小说内容、密码缺失等会列出具体处理结果，不作为“待识别小说”混进书架。自动处理最多嵌套 16 层，单个取出文件上限 8 GB；本机空间不足或源盘断开会显示原因。

## 打开和定位

- **打开小说**：包内文件会自动取出，再交给系统应用。
- **定位小说**：打开资源管理器并选中实际小说文件；包内小说会先自动取出。支持中文、空格、逗号及多层压缩包。
- **定位原压缩包**：选中书库中的原始外层压缩包，和实际小说位置分开。

Windows 定位使用 [`SHOpenFolderAndSelectItems`](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/nf-shlobj_core-shopenfolderandselectitems)，不拼接 Explorer 的 `/select` 参数。

书名和作者从文件名识别。封面是本地排版封面，不是真实出版封面。支持格式筛选、排序、分页，按 `/` 可搜索。

## 去重与更新状态

书架自动合并有效全文指纹相同的文件，以及可信的同书名、同作者记录。仅同名、作者不明或作者不同的作品不会只凭书名合并。来源文件和压缩包都保留，详情中可切换「来源副本」再打开、定位或查看该副本的 AI 清理版；搜索也覆盖被合并来源的书名与作者。优先保留人工确认的书目，否则默认展示已有字数更完整的来源。扫描与本地统计结束后会重新核对分组，源文件改变后不会继续使用失效指纹。

新增互斥的作品更新状态：**连载、断更、完结**，在书卡中作为 tag 展示。断更指有可靠作者最后更新时间，且已经满六个日历月；完结作品不会转为断更。本地文件及压缩包修改日期不作为作者更新时间。没有可靠依据时保留待确认，可在详情「更新状态」填写作者最后更新日期及发布页来源，人工核验不会被后续扫描覆盖。同一本书的来源副本共享人工确认的更新状态。

现有书库先从文件名中的明确标记识别完结/连载；后续本地文字整理还会提取正文简介、结尾的明确标记及作者更新时间，不调用 Claude。状态会随日期自动重新计算，不需要重新扫描才进入断更分类。

筛选采用左侧分组复选栏，支持多选：**同组满足任一项，组间同时满足**。例如同时选择 BL、GL，再选择 ABO，会显示带 ABO 的 BL 或 GL 小说。选项数量是去重后的全库数量，文件格式覆盖所有保留的来源副本；顶部条件按钮可逐项取消，手机上用「筛选小说」展开侧栏。

## 内容分类与字数

- 第一分类：**清水**（无成人性交描写）、**肉文**（有成人性交描写）。
- 第二分类：**BL、GL、GB 女操男、BG、大女主**（女主无 CP）。BG 再分 **1v1、np**（1v2 及以上）。
- 题材 tag 可多选：**末日、ABO、兽世、古代言情、现代言情、星际、虫族、校园**。
- 书卡按「第一分类 第二分类 BG 子分类 题材」显示，例如 `肉文 BG np 末日 ABO`，可组合筛选，也可只看分类不完整的书。
- 在详情中展开「修正分类 / 查看依据」可人工确认。分类存在独立表中，重新扫描不覆盖人工确认，也不会改名或移动原小说。清理版沿用同一书目的分类。

「分类与字数 → 整理新增 / 未统计书目」在本地读取已有文件名、简介和文本特征，不调用 Claude。初筛结果标注待核验；没有依据的字段保持待确认，不能因为没检出露骨词语就认定是清水，也不能因为女主强势就认定无 CP。会尽量排除预收广告、资源网站宣传与其他书的简介。文字提取失败的书可单独重试，不必重读整个书库；有密码的文件先在设置中补上密码。

字数按当前文件中的文字和数字各计 1，不含标点、空白；作者附注仍会计入，因此可能与发布网站的统计口径不同。TXT / TEXT / MD、EPUB / EQPUB、DOCX、HTML / HTM、FB2 可提取文字。各个清理版独立计字，切换版本会切换字数。漫画、扫描 PDF，以及尚不支持的格式显示无法可靠统计，绝不以文件大小估算或用 0 代替。单文件自动读取上限为 64 MB。

本次首次大整理采用本地初筛与人工核验。之后新增书目可以在详情中主动点击「使用 Claude 为本书提出分类建议」，按 AI 设置选择 API 或本机订阅；只发送简介和抽样片段，建议先填入编辑表单，再由你确认保存。**扫描、统计、本地整理不会自动调用 Claude，也不会对整个旧书库发起 AI 请求。**

## Claude 清理与书目版本

1. 在「书库设置 → Claude AI 设置」选择 **Claude API** 或 **本机 Claude Code**。模型为 [`claude-haiku-5-5`](https://platform.claude.com/docs/en/models/haiku-5-5/overview)。API 模式填写 Key，可使用官方 Messages API 或支持此模型及结构化输出的 HTTPS 兼容接口；本机命令行模式复用 Claude 订阅登录，无需 Key。连接测试只发送一条合成测试文字，会占用少量所选方式的用量。
2. 打开一本书，选择输入版本，点击「AI 清理 · 另建版本」。支持 TXT / TEXT / MD、EPUB / EQPUB，以及压缩包内的这些文件；PDF、图片、DOC 等暂不支持清理。
3. 选择作者话 / 广告、乱码修复、屏蔽字推测，生成本地计划。此时尚未发送小说内容。默认检查疑似片段，可改为全文逐段检查；疑似检查可能漏掉没有标记的内容。
4. 核对片段数量、发送文字量和接口地址，再点击发送按钮。任务可停止后续请求，或在失败后从未完成的片段继续；关闭清理窗口后，当前任务仍会继续。可从该书详情返回上次任务，服务重启后仍可继续。
5. 对照原文与建议，勾选需要采用的修改，另存为新版本。高置信度的作者话删除默认勾选；乱码及屏蔽字建议默认不勾选。**屏蔽字只能按上下文推测，无法保证恢复真实原文。** 无效锚点、重复或重叠修改、包含章节标题的删除会被排除。

**所有 AI 修改只写入新文件，不覆盖原文件、原压缩包或已有清理版。** 原版和清理版收在同一书目中，书架只显示一张卡片，可切换版本再打开、定位或继续清理。默认选中最新清理版，也可以随时选回原版。重复点击保存相同方案会返回已保存的版本，避免误生成重复副本。

文本副本输出 UTF-8，保留输入的换行方式；如自动编码识别不对，可手动选择 GB18030 / GBK、Big5 等。EPUB 只修改相关 XHTML 文字，复制其余资源并保留书籍结构；含 DRM 的内容不处理。单个输入上限 64 MB、正文 1600 万字，EPUB 解压后上限 512 MB。

Windows 保存的 API Key 通过当前用户的 DPAPI 加密，接口不会把 Key 回传给页面。迁移到另一台机器后需重新填写；非 Windows 的回退存储仅为本地编码，不提供相同的系统加密。也可通过 `ANTHROPIC_API_KEY` 环境变量提供 Key。书籍内容仍可能包含提示注入，因此模型只生成建议；实际保存由本地校验和人工勾选决定。

### 使用 Claude 订阅

- 先[安装官方 Claude Code](https://code.claude.com/docs/en/setup)，在电脑终端运行 `claude auth login`，选择 Claude 订阅账户登录。
- 在 AI 设置中选择「本机 Claude Code · 使用订阅登录」，程序位置留空自动检测，点击「保存并检测订阅登录」。已有 npm 安装会自动找到对应的本机程序；也可指定完整可执行文件路径，不填写整条命令或额外参数。
- 点击「保存并测试连接」确认当前订阅可以使用所选模型。新建清理计划时会标明当前方式，点击「使用本机 Claude 订阅开始检查」后才发送小说片段。
- 本机模式使用官方 CLI 的[非交互调用和结构化输出](https://code.claude.com/docs/en/headless)。小说片段从标准输入传入；CLI 不启用文件、终端、MCP 等工具，也不保存聊天会话。爱妻的书屿仍按原来的预览、勾选、另存新版本流程处理结果。
- 调用前检查为 `claude.ai` 的 Pro / Max / Team / Enterprise 订阅登录，并在子进程中排除 API Key、自定义 API 地址和第三方云服务环境设置；不会把爱妻的书屿保存的 Key 交给 CLI，也不会自动回退到 API。电脑终端的环境和登录设置不会被修改。登录失效、CLI 超时或额度不足会停止当前任务，可稍后重试。

**本机命令行仍会联网发送片段，占用 Claude Code 订阅额度。** 是否允许超额付费使用由 Claude 账户的额外用量设置决定，参见[额外用量说明](https://support.claude.com/en/articles/12429409-manage-usage-credits-for-paid-claude-plans)。有关订阅登录与 API 认证的优先级，参见 [Claude Code 认证说明](https://code.claude.com/docs/en/authentication)。如遇选项不支持，请更新 Claude Code；此功能已用本机 2.1.267 验证。

## 本机数据

`.data/library.sqlite3` 用于文件索引、压缩包清单、书目版本关系和必要的设置。旧版本数据库中的废弃阅读字段不再读取或更新，新数据库不会创建这些字段。

`.data/tools` 为便携解压引擎，`.data/extracted` 为自动取出缓存。停止服务后可以清理缓存，下次需要时会自动重建。不要删除书库中的原文件。

`.data/versions` 存放另存的清理版，**请和数据库一起备份，不要当作缓存删除**。`.data/cleaning` 保存本地任务、输入快照和修改建议，支持中断后继续。这些目录被排除在扫描之外，不会变成额外书目；整个 `.data` 不提交到 Git。

分类和字数同样保存在 `.data/library.sqlite3`，`.data/classification` 保存本地批处理进度与整理报告。字数结果会按源文件版本复用。

服务默认只监听 `127.0.0.1`，网页版通过隧道访问；带 `--lan` 时还会监听局域网。除本机直接访问外，所有请求都需要登录令牌。令牌保存在数据库的 `sessions` 表，访问密码只保存加盐哈希。页面不加载外部字体、图片或脚本。每小时扫描一次新增内容，磁盘临时断开时保留已知索引。
