# 书屿 · 我的小说

只做三件事：找到书库里有什么小说、搜索、打开或定位文件。不提供内置阅读器，不记录阅读历史、阅读状态、收藏、标签或笔记。

## 启动

双击 **启动书屿.bat**，浏览器会打开 <http://127.0.0.1:8765>。保持启动窗口开启；关闭窗口即停止服务。更新代码后，关闭旧服务，再重新启动并刷新页面。

需要 Python 3.10 或更新版本。默认扫描 `Z:\老婆小说漫画`。

```powershell
python server.py
python server.py --root "D:\我的小说" --port 8766
python server.py --no-browser
```

## 自动处理压缩包

- 汇总所有子目录，不要求先整理文件夹。
- 自动逐层展开 ZIP、RAR、7Z、CBZ、CBR 等压缩包，直接把包内小说列到书架上，包括多层套包。
- 纯图片压缩包或纯图片目录作为一部漫画展示，不逐张列图。
- TXT、EPUB / EQPUB、PDF、DOCX、DOC、MOBI、AZW / AZW3、RTF、MD、HTML、FB2 等按书目展示；内容交给系统关联应用打开。
- 初次运行会从 [7-Zip 官方发布](https://www.7-zip.org/download.html)下载并校验便携解压引擎，放在 `.data/tools`，不安装到系统。准备好后可离线使用。
- 只在项目的 `.data/extracted` 中缓存需要取出的嵌套压缩包和文件，不改动源目录，不要求逐个手动解压。
- 未变化的目录清单及已取出的文件会复用缓存。首次扫描大量嵌套合集可能较慢，扫描期间已有结果仍可搜索。手动扫描会自动重试失败的压缩包。

确有密码的文件仍需要正确密码。在「书库设置」填写常用解压密码，每行一个，程序会自动尝试并重新扫描。密码只保存在本机，服务不会把小说或密码上传到网络。

损坏、缺卷、没有小说内容、密码缺失等会列出具体处理结果，不作为“待识别小说”混进书架。自动处理最多嵌套 16 层，单个取出文件上限 8 GB；本机空间不足或源盘断开会显示原因。

## 打开和定位

- **打开小说**：包内文件会自动取出，再交给系统应用。
- **定位小说**：打开资源管理器并选中实际小说文件；包内小说会先自动取出。支持中文、空格、逗号及多层压缩包。
- **定位原压缩包**：选中书库中的原始外层压缩包，和实际小说位置分开。

Windows 定位使用 [`SHOpenFolderAndSelectItems`](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/nf-shlobj_core-shopenfolderandselectitems)，不拼接 Explorer 的 `/select` 参数。

书名和作者从文件名识别。封面是本地排版封面，不是真实出版封面。支持格式筛选、排序、分页，按 `/` 可搜索。

## 本机数据

`.data/library.sqlite3` 只用于文件索引、压缩包清单和必要的书库设置。旧版本数据库中的废弃阅读字段不再读取或更新，新数据库不会创建这些字段。

`.data/tools` 为便携解压引擎，`.data/extracted` 为自动取出缓存。停止服务后可以清理缓存，下次需要时会自动重建。不要删除书库中的原文件。

服务只监听 `127.0.0.1`；页面不加载外部字体、图片或脚本。每 5 分钟扫描新增内容，磁盘临时断开时保留已知索引。

## 验证

```powershell
python -m unittest discover -s tests -v
node --check web/app.js
# 可选：界面交互测试，仅开发时需要 Node.js
npm ci
npm test
```

测试使用临时书库，不修改真实小说目录，也不启动真实阅读应用。7-Zip 密码用例在引擎可用时执行，测试不会联网安装工具。
