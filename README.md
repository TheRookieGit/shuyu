# 书屿 · 本地小说管理器

一个只在本机运行的中文书架。默认扫描 `Z:\老婆小说漫画`，保留原有目录和文件，不搬动、不重命名、不解压写入源目录。界面与服务均不依赖在线服务。

## 启动

双击 **启动书屿.bat**，浏览器会打开 <http://127.0.0.1:8765>。保持启动窗口开启；关闭窗口即停止服务。再次双击可重新打开已有服务。

需要 Python 3.10 或更新版本；当前电脑已安装 Python 3.14，无需安装其他依赖。

也可以在当前文件夹运行：

```powershell
python server.py
# 指定其他书库、端口
python server.py --root "D:\我的小说" --port 8766
# 不自动弹出浏览器
python server.py --no-browser
```

## 管理书库

- 自动递归扫描子文件夹。启动时扫描，运行期间每 5 分钟再次扫描，也可以点「扫描书库」。
- 搜索书名、从文件名识别的作者、标签和相对路径；可按文件夹、格式、收藏及阅读状态筛选。
- 封面和列表两种视图，支持排序、分页和最近阅读。
- 收藏、阅读状态、标签和笔记保存在本机。文件暂时无法读取时会显示说明；磁盘离线或扫描不完整时不会清空书架。
- 在「书库设置」中更换根目录；不同路径的书库记录各自保存。文件被移动或重命名后视为新条目。

## 阅读格式

| 格式 | 支持情况 |
| --- | --- |
| TXT / MD | 自动尝试 UTF-8、UTF-16、GB18030、Big5；识别章节，分页、目录、字号、三种配色、保存阅读位置 |
| EPUB / EQPUB | 通过 EPUB 容器和 spine 顺序提取文字；以清爽文字模式阅读，暂不还原原排版及书内插图；EQPUB 仅在文件内容实际为 EPUB 时可读 |
| DOCX / HTML / FB2 | 提取文字，使用文字阅读器 |
| PDF | 浏览器内置 PDF 阅读器；记录最近打开，不记录 PDF 页码（由浏览器管理） |
| ZIP / CBZ | 浏览包内文件，直接读支持的文字或 PDF、翻看图片；无需解压到源目录 |
| RAR / CBR / 7Z | 使用 Windows 自带 `tar` 浏览和读取；实际可读性依赖压缩方法。加密、多卷、损坏或不支持的压缩包需先自行解压 |
| 图片文件夹 | 每个含图片的目录作为一个相册；按自然序翻看图片，记住上次位置 |
| MOBI / AZW / AZW3 / DOC / RTF | 纳入书架，调用已安装的系统应用打开，不在应用内解析 |
| 包内嵌套压缩包和其他文件 | 可下载后自行打开；暂不递归索引嵌套压缩包 |

单个包内文件及文字读取上限 96 MB。首次扫描只索引文件信息，打开压缩包时才读取清单，适合网络盘中的大量文件。封面为按书名生成的本地排版封面，并非出版社真实封面。

阅读时 `←` / `→` 翻页，`Esc` 返回或关闭目录。书架页面按 `/` 搜索。漫画每张图算一页，可滚动阅读长图。

## 数据与备份

索引、书库设置及阅读记录保存在项目下的 `.data/library.sqlite3`。

「书库设置」支持导出 JSON 记录及恢复，按当前书库中的相对路径匹配，恢复会覆盖匹配条目的记录。JSON 上传上限约 1.9 MB；完整迁移请停止服务后备份整个 `.data` 文件夹。书籍本身需要自行备份。

服务只监听 `127.0.0.1`，浏览器页面不加载外部字体、图片或脚本。新增文件只有服务运行时才会自动扫描。暂不支持多用户、远程访问、云同步、全文检索或自动移动整理源文件。
