登录书屿

从 Windows 书库里选一本 TXT 或 EPUB，让 Claude 找出要改的地方。每一处都由你确认，确认后另存为这本书的新版本，原文件和已有版本都不会改动。

1选一本小说

    书名和作者会从文件名和书里自动识别，需要的话可以修改。压缩包会在 Windows 电脑上自动解压（包括包中包），把里面的每本小说识别书名作者后单独保存。小说和压缩包都保存在 Windows 书库的「Lite上传」文件夹里，以书名和作者命名，并标注【lite上传】；完整版书屿里也能看到。

    全部版本与下载

      2要做什么

      写清楚要改什么、改成什么。Claude 只做局部修改，不会改写情节；没把握的地方会保持原样。

      疑似片段检查可能漏掉没有明显标记的内容。屏蔽字只是根据上下文推测，不能保证是原文；乱码和屏蔽字的建议默认不勾选。

      生成计划只在 Windows 电脑上读文件，不会发送任何内容。

      3检查并确认

      3依次处理这一批

        一本接一本处理，每本同时发送 4 个片段；关掉页面也会继续。处理完的书点「确认建议」逐条确认后另存版本。

        已另存为新版本

        原文件和之前的每个版本都保留着，可以在「全部版本与下载」里随时下载，也可以在完整版书屿的书目详情里找到。

        Lite 的 Claude 设置

        使用 Windows 电脑上 Claude Code 的订阅登录，不需要 API Key。

        连不上 Windows 电脑上的书屿

        书屿 Lite 的书和 AI 处理都在 Windows 电脑上进行。请确认：

        • 电脑已经开机，没有睡眠；
        • 书屿正在运行（右下角托盘里有书屿图标；关掉窗口不会停止它）；
        • Tailscale 已经连上。
