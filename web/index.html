CLAUDE AI

AI 清理设置

开始检查时，所选小说片段会发送到上面的接口，并产生 API 用量。Windows 使用当前用户的系统加密保护已保存的 Key。

复用终端里的 Claude 订阅登录，无需填写 API Key。首次使用可在电脑终端运行 claude auth login，选择订阅账户登录。

片段仍会发送到 Claude 服务，占用 Claude Code 订阅额度；超额是否计费取决于 Claude 账户的额外用量设置。未登录或额度不足时会停止，不切换到 API。

测试连接会发送一条测试文字，占用少量所选方式的用量。
REVIEW BEFORE SAVING

AI 清理

原文件始终保留。每次保存都会另建版本，收在同一本书里。

疑似片段检查可能漏掉没有明显标记的内容。屏蔽字是上下文推测，不能保证原文；乱码和屏蔽字建议默认不勾选。EPUB 会保留电子书结构。

停止会等待当前请求结束，已完成的建议会保留。关闭窗口后任务仍会继续，可从书目详情返回。API 与本机命令行可在设置中切换。
